# mathkid · 口算小达人

儿童数学口算网页游戏，手机 / 平板自适应，单文件、可离线，UI 采用 Ink Candy 风格（墨线描边 + 厚块按钮）。
视觉规范来自 [game-ui](https://github.com/maitrithanh/game-ui-skill) 技能包（kit.css / kit.js 已内联）。

- 60 题随机（加减乘除各 15 题），限时 10 分钟
- 加法：和 ≤ 100；减法：被减数 ≤ 100
- 乘法：最大 6×6；除法：最大 36÷6，全部整除
- 结算显示正确率、用时、答对/答错/未答与错题回顾

在线玩：https://ipunkid.github.io/mathkid/
